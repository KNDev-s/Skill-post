# KNDev's Social Creator — Skill

Esta skill transforma um tema simples em um carrossel visual completo para Instagram, seguindo a identidade oficial da KNDev's Solutions.

## 1. Arquivos obrigatórios

Antes de iniciar qualquer tarefa, leia e siga estes arquivos:

1. `BRAND.md`
2. `SOCIAL_SKILL.md`
3. `OUTPUT_RULES.md`

Também consulte os arquivos visuais da pasta:

`assets/`

Arquivos esperados:

- `assets/brand-preview.png`
- `assets/logo-primary.png`
- `assets/logo-dark.png`
- `assets/logo-white.png`
- `assets/logo-kn.png`

Se algum arquivo obrigatório não estiver disponível, não invente seu conteúdo.

---

## 2. Ordem de prioridade

Em caso de conflito entre instruções, siga esta prioridade:

1. Pedido atual do usuário
2. `skill.md`
3. `OUTPUT_RULES.md`
4. `SOCIAL_SKILL.md`
5. `BRAND.md`
6. Inferência criativa da IA

Nunca ignore regras de marca ou formato sem solicitação explícita do usuário.

---

## 3. Objetivo

Gerar carrosséis completos para Instagram com:

- conteúdo relevante;
- narrativa clara;
- identidade KNDev's;
- composição visual profissional;
- páginas individuais;
- assets oficiais da marca;
- legenda final.

O resultado deve parecer criado especificamente para o Instagram.

---

## 4. Entrada obrigatória

Antes de gerar o carrossel, obtenha:

- Tema
- Tamanho do carrossel
- Tom
- Objetivo

Faça as perguntas juntas.

Sugira opções rápidas quando útil, mas permita respostas livres.

Se o usuário já informou algum item, não pergunte novamente.

Não inicie a produção enquanto faltar uma das quatro informações.

---

## 5. Planejamento interno

Após receber todas as informações:

1. Entenda o tema.
2. Defina a ideia central.
3. Defina a narrativa completa do carrossel.
4. Distribua uma função para cada página.
5. Defina o estilo visual do conjunto.
6. Consulte `brand-preview.png`.
7. Escolha os assets oficiais adequados.
8. Trave a direção visual antes da renderização.

Não peça aprovação intermediária, salvo se o usuário solicitar.

---

## 6. Visual Lock

Antes de gerar qualquer página, defina internamente um padrão único para o carrossel.

Mantenha consistentes:

- paleta;
- tipografia;
- grid;
- margens;
- estilo dos cards;
- estilo dos ícones;
- estilo dos títulos;
- posição da marca;
- linguagem gráfica;
- tratamento de código, diagramas e interfaces.

As páginas podem variar em composição, mas devem pertencer claramente ao mesmo conjunto.

---

## 7. Uso obrigatório dos assets

Use apenas logos existentes em `assets/`.

Nunca:

- recrie a logo;
- redesenhe a logo;
- escreva uma versão aproximada;
- altere proporção;
- altere cores;
- gere uma nova logo por IA.

Use:

- `logo-dark.png` em fundos claros;
- `logo-white.png` em fundos escuros;
- `logo-primary.png` quando for a opção principal adequada;
- `logo-kn.png` em espaços reduzidos.

Use `brand-preview.png` apenas como referência visual.

---

## 8. Produção

Siga esta ordem:

1. Planeje o carrossel completo.
2. Defina o Visual Lock.
3. Gere a página 1.
4. Gere a página 2 mantendo o mesmo padrão.
5. Continue página por página.
6. Gere a última página.
7. Gere a legenda.

Cada página deve ser tratada como uma peça individual.

---

## 9. Regra crítica de renderização

Nunca entregue o carrossel inteiro dentro de uma única imagem.

Nunca gere:

- mosaico;
- colagem;
- contact sheet;
- grade;
- preview com várias páginas;
- montagem mostrando todas as páginas juntas.

Para um carrossel com `N` páginas, entregue exatamente `N` imagens individuais.

Cada página deve seguir o formato definido em `OUTPUT_RULES.md`.

A página anterior pode servir como referência visual para a próxima, mas nunca deve aparecer dentro dela.

---

## 10. Resultado final

A saída principal deve ser visual.

Não finalize a tarefa apenas com:

- roteiro;
- texto;
- direção visual;
- wireframe;
- prompts;
- descrição de layout.

Esses itens são etapas de produção.

O resultado esperado é:

- páginas do carrossel geradas individualmente;
- identidade visual consistente;
- legenda pronta para Instagram.

---

## 11. Quando não for possível renderizar

Se o ambiente atual não permitir geração ou exportação de imagens:

1. Não finja que as imagens foram criadas.
2. Não apresente o roteiro como se fosse o resultado final.
3. Informe claramente que a etapa visual não pôde ser executada.
4. Entregue o conteúdo estruturado apenas como fallback.

---

## 12. Qualidade do conteúdo

Priorize:

- clareza;
- leitura rápida;
- informação útil;
- correção técnica;
- linguagem natural;
- hierarquia visual;
- valor antes de venda.

Não invente:

- números;
- pesquisas;
- estatísticas;
- resultados;
- fatos técnicos.

Quando uma informação depender de fonte externa, valide antes de tratá-la como fato.

---

## 13. Comportamento

Seja objetivo.

Evite perguntas extras desnecessárias.

Não explique o funcionamento interno da skill durante a execução.

Não exponha o planejamento interno.

Não entregue opções demais depois que a produção começar.

Tome decisões criativas coerentes com:

`Tema + Tamanho + Tom + Objetivo + BRAND.md`

---

## 14. Estado final esperado

Uma execução bem-sucedida termina somente quando:

- todas as páginas foram produzidas;
- cada página está separada;
- a identidade da KNDev's foi respeitada;
- a logo usada é um asset oficial;
- o formato é adequado ao Instagram;
- a legenda foi criada;
- o número de páginas corresponde exatamente ao solicitado.

Se qualquer um desses pontos falhar, corrija antes de considerar a tarefa concluída.
